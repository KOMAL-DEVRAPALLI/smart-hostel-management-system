# Hostel Management System

## Overview
A full-stack web application for managing hostel operations including students, rooms, fees, and complaints.

## Features
- Student Management
- Room Allocation
- Fee Tracking
- Complaint Management
- Authentication
- Dashboard

## Tech Stack
Frontend: React.js
Backend: Node.js, Express.js
Database: MongoDB

## Installation
npm install
npm run dev

## Future Improvements
- Email Notifications
